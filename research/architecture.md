# Прийнята архітектура

Погоджено: панель + Locator, зворотне геокодування, FastAPI на Railway,
персональні відкличні токени, MIT для власного коду плагіна.

Плагін → HTTPS Bearer → FastAPI → Visicom Data API 5.0 (ключ лише на сервері).
Моделі у core/models.py незалежні від QGIS і повторно використовуються сервером.
Один серверний екземпляр, SQLite на Volume; квота резервується BEGIN IMMEDIATE.
Плагін використовує QgsTask і QgsNetworkAccessManager; Locator працює у власному
worker, а prepare() розблоковує Auth Manager у GUI-потоці.

У Qt імпортовані лише qgis.PyQt; плагін підтримує Python 3.9, сервер Python 3.12.
Basic-конфігурація Auth Manager є лише зашифрованим контейнером токена;
мережевий клієнт сам додає Bearer, а не HTTP Basic. Зміна URL потребує нового токена.
Мережеві редиректи вимкнені, щоб не передавати токен іншому хосту.

Без пакетного геокодування, експорту, власної карти, реєстрації та проксі
довільних upstream URL. Публікація й Railway deploy — окремий запит.

Під час інтеграційного тестування виявлено, що QGIS ігнорує префікси сторонніх
плагінів коротші за 3 символи. Замість початкового ua використовується uas.
Джерело: https://api.qgis.org/api/3.28/classQgsLocatorFilter.html#prefix
