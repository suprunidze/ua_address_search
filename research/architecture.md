# Прийнята архітектура

Погоджено: панель + Locator, зворотне геокодування, FastAPI на Railway,
персональні відкличні токени, MIT для власного коду плагіна.

Railway: плагін → HTTPS Bearer → FastAPI → Visicom Data API 5.0 (спільний ключ на сервері).
Прямий режим: плагін → HTTPS Visicom, власний ключ у QGIS Authentication Manager.
Моделі у core/models.py незалежні від QGIS і повторно використовуються сервером.
Один серверний екземпляр, SQLite на Volume; квота резервується BEGIN IMMEDIATE.
Плагін використовує QgsTask і QgsNetworkAccessManager; Locator працює у власному
worker, а prepare() розблоковує Auth Manager у GUI-потоці.

У Qt імпортовані лише qgis.PyQt; плагін підтримує Python 3.9, сервер Python 3.12.
Basic-конфігурація Auth Manager є лише зашифрованим контейнером токена;
мережевий клієнт сам додає Bearer, а не HTTP Basic. Зміна URL потребує нового токена.
Мережеві редиректи вимкнені, щоб не передавати токен іншому хосту.

Без пакетного геокодування, експорту, власної карти та проксі
довільних upstream URL. Публікація й Railway deploy — окремий запит.

Під час інтеграційного тестування виявлено, що QGIS ігнорує префікси сторонніх
плагінів коротші за 3 символи. Замість початкового ua використовується uas.
Джерело: https://api.qgis.org/api/3.28/classQgsLocatorFilter.html#prefix

## Версія 0.1.0.3

- Префікс адр; підтримку кирилиці перевірено у реальному Locator QGIS3/4.
- SessionCache у core/cache.py: спільний між QgsTask і клонами Locator, 128 МіБ,
  JSON-копії результатів, LRU, без TTL, single-flight та незалежне скасування.
- Cache namespace: URL сервера й SHA-256 токена; при зміні авторизації кеш
  очищається, незавершені старі запити не можуть його наповнити повторно.
- Точка: штатний flashGeometries і постійний маркер; геометрія лише за дією.
  Тимчасові memory-шари MultiPoint/MultiLineString/MultiPolygon зберігають атрибуцію.
- JSON-журнал INFO явно налаштований на stdout. Заголовок X-UAAS-Session-ID
  додається до вже потрібних запитів; окремого connection/telemetry запиту немає.
- Персональні ліміти задаються env JSON за хешем токена; SQLite не мігрується.

## Версія 0.1.0.4

- Два режими Credentials зі спільними моделями й мережевими засобами QGIS;
  namespace прямого режиму відокремлений від Railway. Секрети зберігаються окремо.
- Anonymous enrollment: UUID інсталяції та 256-бітний випадковий Bearer-секрет
  зберігаються до першого HTTP; сервер тримає хеш і не перевидає його при повторі.
  Реєстрація — ідентичність інсталяції, не перевіреної особи. SQLite отримує дві
  нові таблиці, чинні токени, override 1000 і лічильники залишаються незмінними.
- Автоматична геометрія вибраного першого результату (також reverse/Locator)
  керується збереженим чекбоксом. Locator не отримує геометрію під час набору тексту.
  Незалежні покоління задач пошуку й геометрії захищають від застарілих відповідей.
- Quota snapshots у відповідях зберігаються окремо від кешу результатів, порівнюються
  за observed_at; queued Qt-сигнал оновлює панель також після запитів Locator.
  Кешовані повтори не створюють запитів квоти. Мережевий дисковий кеш вимкнений.
- Мережевий транспорт використовує thread-local QgsNetworkAccessManager та Qt event loop
  із явним abort, граничним часом і очищенням reply. Це закриває відтворене зависання
  blockingGet при скасуванні між перевіркою feedback і створенням мережевого запиту.
- LocalUsage: спільний для профілів комп’ютера SQLite, ключ — SHA-256 власного API-ключа
  і доба Europe/Kyiv (Qt fallback Europe/Kiev). BEGIN IMMEDIATE рахує фактичні спроби
  відправлення, помилки й геометрію; налаштована межа лише попереджає, не блокує.
- Публікація сервера виконується раніше за розповсюдження плагіна; поки сервер
  попередній, старі токени працюють, але нова реєстрація й метадані квоти недоступні.

## Версія 0.1.0.6

- Режим зворотного пошуку — toggle, синхронізований через canvas.mapToolSet.
  Службове скасування задач відділене від повного cancel; запити не вимикають режим.
- MapDisplay володіє власними QgsRubberBand і QVariantAnimation для flash;
  clear зупиняє анімації та прибирає тільки власні елементи сцени, без впливу на шари.
  Кнопка cancel доступна за наявності задач, режиму кліків або накладок.
- Довідка resources/help.html входить до runtime allowlist пакувальника;
  QDesktopServices відкриває її через QUrl.fromLocalFile без зміни стану пошуку.
- Налаштування використовують мінімальний розмір компонування, WrapLongRows
  і adjustSize при зміні режиму, шрифту або стилю.

## Версія 0.1.0.7

- MapDisplay.show приймає recenter: звичайний вибір переміщує карту, явне
  завантаження геометрії лише підсвічує. Прапорець download_requested зберігається
  при приєднанні до активної задачі; поточний вигляд не відновлюється зі старого знімка.
- Новий memory-шар заповнюється до додавання до проєкту. На час додавання
  вимикається autoSetupOnFirstLayer у штатному layerTreeCanvasBridge, виконується
  setCanvasLayers; попередній параметр відновлюється через finally.
- Налаштування обчислюють мінімальну ширину (від 500 логічних px) і висоту для
  цієї ширини, застосовують setFixedSize при зміні режиму, шрифту або стилю.
- ClientError зберігає структурований код і знімок квоти. SessionCache передає
  daily_quota через Qt-сигнал до GUI після перевірки скасування та авторизації.
  Панель і клони Locator користуються одним каналом повідомлень.
- Немодальний QuotaDialog показується один раз для пари авторизація/доба протягом
  сесії. Він не визначає вид добового ліміту. Перехід у режим власного ключа
  відкриває звичайний SettingsDialog; зміни зберігаються лише його кнопкою.
- Help HTML описує користувацькі дії й практичну поведінку квоти без серверних
  подробиць. Сервер, API, ліміти й алгоритми обліку в цій версії не змінені.
