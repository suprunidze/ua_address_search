Перший пошук

  1. Відкрийте панель Visicom Data API for QGIS через іконку плагіна.
  2. У налаштуваннях виберіть спільний доступ Railway або введіть власний ключ Visicom.
  3. Введіть адресу, наприклад Київ, Хрещатик, 26, і натисніть Enter або «Знайти». Мінімум — три символи.
  4. Перший результат вибирається автоматично. Карта показує його точку з flash; натисніть інший результат, щоб перейти до нього.

Також працює рядок пошуку QGIS (Locator): адр Київ, Хрещатик, 26. Пошук починається після паузи 1 секунда. Без префікса плагін не виконує запитів.

Скасування залишає список результатів, кеш і завантажені шари. Накладки інших плагінів не змінюються. Вибір іншого інструмента QGIS вимикає режим кліків. Повторний клік по карті замінює попередній незавершений пошук.

Геометрія та кеш

Чекбокс «Автоматично отримувати геометрію» зберігає свій стан. Якщо він увімкнений, вибраний результат автоматично показується з повною геометрією; якщо вимкнений — лише точка. Під час набору тексту в Locator геометрія не завантажується.

Перший пошук зазвичай потребує одного запиту адреси й окремого запиту повної геометрії. Геометрія залежить від об’єкта: точка, лінія або полігон.

Панель і Locator повторно використовують уже знайдені адреси та отриману геометрію протягом робочої сесії. Позначка «З кешу сесії» показує, що повтор не витратив запиту. Регістр і зайві пробіли не створюють нового пошуку. Для старих результатів іноді може знадобитися новий запит.

Закриття панелі та зміна проєкту зберігають кеш. Зміна провайдера або ключа та вивантаження плагіна його очищають. Помилки не кешуються.

Завантажені шари — тимчасові, EPSG:4326, окремо для точок, ліній і полігонів; вони містять ID, назву, адресу, категорію й атрибуцію. За потреби збережіть їх засобами QGIS перед закриттям проєкту.

Доступ і квоти

Спільний доступ Railway

Виберіть спільний доступ у налаштуваннях — власний ключ для цього режиму не потрібний. Доступний залишок видно внизу панелі. Якщо QGIS попросить головний пароль, розблокуйте його захищене сховище.

Коли добову квоту вичерпано, з’явиться вікно з пропозицією дочекатися наступної доби або отримати власний ключ. Раніше знайдені адреси й уже отримана геометрія залишаються доступними з кешу; завантажені шари зберігаються.

Зареєструватися та отримати ключ Visicom. Після отримання ключа натисніть «Налаштування», виберіть «Власний ключ Visicom API», вставте ключ і натисніть «Зберегти». Режим не перемикається автоматично.

Власний ключ Visicom API

Введіть власний ключ у налаштуваннях. За бажанням увімкніть показ залишку й укажіть добовий ліміт — початкове значення 1500. Ключ захищає сховище QGIS.

Локальна оцінка враховує лише цей плагін на комп’ютері, спільно для його профілів QGIS3/QGIS4. Використання ключа іншими програмами або комп’ютерами невідоме. Перевищення попереджає, але не блокує запити; Visicom застосовує власні межі.

Якщо показ залишку вимкнений, видно кількість запитів. Кешовані повтори квоту не витрачають. Нова доба починається опівночі за київським часом. Якщо Visicom відмовляє в запиті, плагін показує повідомлення; автоматичних повторів немає.

Якщо не працює

  • Перевірте режим доступу, інтернет і повідомлення над чекбоксом геометрії.
  • Для власного ключа перевірте його в налаштуваннях. Для відкликаного спільного доступу зверніться до адміністратора сервера.
  • При перевищенні хвилинного ліміту зачекайте. Добова квота оновлюється після початку нової доби; автоматичних повторів запитів немає.
  • Найближча адреса — це об’єкт у радіусі 50 м, а не обов’язково адреса саме тієї будівлі, по якій зроблено клік.
  • Після оновлення файлів плагіна перезапустіть QGIS.

Об’єкти

Виберіть або введіть коди категорій Visicom через кому. Текст необов’язковий. Можна шукати по Україні, у радіусі однієї точки, в охопленні карти або всередині одного виділеного полігона активного шару. Ліміт — до 250 результатів. Досягнення ліміту означає, що вибірка може бути неповною.

Поле ID дозволяє отримати до 250 об’єктів із геометрією одним запитом замість пошуку за категоріями. Результати видно в таблиці; виберіть рядок для показу на карті. Кнопка додавання створює окремі шари для точок, ліній і полігонів.

Маршрут

Введіть точки в порядку старт → проміжні точки → фініш. До 27 точок загалом, з них до 25 проміжних. Додайте їх вручну, кліками або з точкового шару. Для шару виберіть унікальне поле порядку; можна взяти лише виділені об’єкти. Стрілки змінюють порядок рядків, «−» видаляє вибрану точку.

Режими: автомобільний оптимальний, автомобільний найкоротший і по прямій. Блокування проїздів доступні лише для автомобільних режимів. Результат — довжина в метрах і лінія маршруту; час у дорозі не розраховується.

Матриця відстаней

Задайте до 25 початкових і до 25 кінцевих точок. Повертається таблиця для кожної пари з ID джерела, ID призначення, відстанню в метрах і статусом. Недоступна пара має порожню відстань, а не нуль.

Оптимізація відвідування

Задайте від 2 до 50 точок. Перша є стартом; без повернення до старту остання також фіксується як фініш. Результат — порядок відвідування й точки з номерами. Дорожня лінія не входить у цей результат.

Окрема кнопка побудови дорожньої лінії витрачає додатковий запит. До списку додається старт, якщо маршрут замкнений. Увесь список має вкладатися в ліміт маршруту — максимум 27 точок; автоматичного розбиття немає.

Прив’язка до доріг

До 250 точок можна прив’язати до автомобільної мережі або всіх доріг. Для треку важливий порядок точок. Опція інтерполяції повертає лінію вздовж дороги; незалежна прив’язка розглядає точки окремо й вимикає інтерполяцію. Прив’язка є результатом сервісу, а не підтвердженням фактичного пересування.

Пакетна робота Processing

У панелі інструментів Processing відкрийте Visicom Data API for QGIS. Доступні вісім алгоритмів: геокодування таблиці, зворотне геокодування, пошук об’єктів, отримання за ID, маршрут, матриця, оптимізація та прив’язка.

Processing працює лише з власним ключем Visicom. Збережіть його в налаштуваннях плагіна. Після цього можна повернути панель на спільний доступ: алгоритми все одно використовуватимуть власний ключ. Ключ не вводиться в параметрах алгоритму. Локальний облік запитів спільний із панеллю.

Виберіть потрібні виходи: точки, лінії, полігони й таблиця; їх можна записати у файл або залишити тимчасовими. Результати зберігають ID вхідних записів, ранг збігів, порядок відвідування та статус. За відсутності збігів залишається запис без геометрії. Після помилки або скасування стан показує часткове виконання.

Завеликі набори відхиляються до запиту з поясненням ліміту. Геокодування таблиці й зворотне геокодування виконують послідовні запити; однакові запити беруться з кешу. Інші операції виконуються одним запитом на набір. Автоматичних повторів і розбиття немає. Для нових операцій через Railway потрібне оновлення сервера.
